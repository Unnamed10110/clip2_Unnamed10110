clip2 — dark preset themes
Seven presets for kThemePresets. One system: every role shares a fixed OKLCH lightness and chroma, and hue is the only variable — so the set stays consistent, and the text role keeps the low chroma that reads calm on pure black instead of neon. Graphite is the deliberate exception, holding the same lightness ladder at zero chroma.
The accent cannot go dark
ApplyThemeId hardcodes SEL_FG = RGB(0,0,0), and that black is the text drawn on the selected row — which is filled with selBg. So the accent has to stay luminous enough for black text to read on it. Every accent below clears 10:1 against black. Darkness comes from the background (BG is pure black) and from the washes, which are only 15% of the accent.

Dropping these in
No other code changes: the Settings dropdown is built from THEME_COUNT and kThemePresets[t].name, so it picks these up on its own. Append only — the active theme is persisted to the registry as a raw index, so inserting in the middle would silently change theme for anyone who already picked one.
